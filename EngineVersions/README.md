| Directory | Status | Purpose |
|---|---|---|

| UE6 | Future migration target | Planning until official SDK/source is available |
| UE7 | Hypothetical future target | Reserved planning workspace; no API assumptions |
| UE8 | Hypothetical future target | Reserved planning workspace; no API assumptions |

| UE10 | Hypothetical future target | Reserved planning workspace; no API assumptions |
