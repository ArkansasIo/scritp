# Unreal Source and Repository Policy

Unreal Engine source access is governed by Epic Games' applicable license and access process. This project repository must not redistribute Epic's licensed engine source or binaries.

- Clone source directly from the official Epic Games repository after account authorization.
- Store the checkout in ignored local LocalEngine/ or another private local path.
- Never commit engine source, generated binaries, Intermediate, Saved, DerivedDataCache or downloaded dependencies.
- Do not upload Epic source to unrelated public repositories, artifacts, mirrors or releases.
- Share project-owned plugins and documentation only when their licenses allow it.

Official guide: https://dev.epicgames.com/documentation/unreal-engine/downloading-source-code-in-unreal-engine

The UE6–UE10 directories contain only project-authored migration notes. They do not claim that those engine versions are available.
